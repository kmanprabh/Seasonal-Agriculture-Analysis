#  Seasonal Agriculture Performance Analysis

This project focuses on analyzing agricultural performance across different seasons — **Kharif, Rabi, and Zaid**. The aim is to understand how factors such as weather conditions, resource usage, crop type, and farming practices affect agricultural performance.

The dataset contains **4,000 records and 28 features**, including crop yield, rainfall, temperature, soil conditions, irrigation methods, fertilizer usage, production, revenue, profit, and disease/pest risk.

##  What I Analyzed

* Crop yield and production across different seasons
* Crop-wise performance
* Rainfall, temperature, and soil conditions
* Water and fertilizer usage
* Performance of different irrigation methods
* Revenue and profit across seasons
* Disease and pest risk
* Relationships between environmental factors and crop performance

I also used **correlation analysis and ANOVA** to better understand the relationships and differences present in the data.

##  Tools Used

* Python
* Google Colab
* Pandas & NumPy
* Matplotlib & Seaborn
* SciPy

##  Conclusion

The analysis helps highlight how agricultural performance changes across seasons and how environmental conditions and resource usage are related to crop outcomes. These insights can be useful for making better seasonal farming and resource-planning decisions.
